# 同轴手柄 v1（2026-10-11）

Historical PCB1_5 design description. Its superseded model exports, renders and task-specific generators were removed on 2026-10-28. The original handle inputs remain in `../inputs`; this folder retains `inputs/`, `cache/pcb_parts.json`, `cache/pcb_parts.npz` and `extract_pcb_parts.py` for `../check_facts.py`. Current PCB1_2 work is in [the twist-key handoff](../../Handle_TwistKey_2026-10-27/HANDOFF.md). The design notes below are retained as source evidence, not a current deliverable.

本设计所依据的事实及复核方法见 [../VERIFIED_FACTS.md](../VERIFIED_FACTS.md)。修改前先运行 `../check_facts.py`。

## 设计方向（Hsinlung 10-11 确认）

- 杖口与手柄**同轴**（直柄），不采用 L/T 形。
- PCB1_5 不改。15 个模组**直接焊在板上**。
- 原尾端敞口不是有意设计，本版封口。

## 握持段改了什么

| 项目 | 原手柄 | v1 |
|---|---|---|
| 握持段截面 | 46 × 35.5 mm 方盒，小倒角 | 41.3 × 32.3 mm，上角 R10.6、下角 R11.8 |
| 握持段外周长 | 159.8 mm | 128 mm（约 −20%） |
| 总长（含杖口） | 270 mm | 238 mm |
| 电池段最低点 | Y −31 | Y −22.3 |
| 尾部止挡 | X 220–230（多数手够不到） | X 176–198，位于掌根附近 |

- 宽度受 PCB 板宽（35.7 mm）限制；高度由 ESP 开发板（上）和电解电容（下，板下 7.75 mm）决定。在 PCB 不改的前提下，128 mm 已接近下限。
- 电池段后沿做成平缓台阶（X 67–96），可托住食指，防止手往杖口方向滑。
- 触点面与握持段顶面在 Y 23.5 连续齐平，拇指从握持段滑到阵列上没有台阶。
- 握持段内没有螺钉和开口，只有侧下方一条止口缝（Y 1.5）。

## 内部对位（按设计数据，不按占位模型）

- **PCB 位置**：按 PCB1_5 实际焊孔居中，比 Codex 各模型往 +Z 移 2.75 mm。
  - 板顶取 Y 3.5，焊上的模组顶面（板顶 + 20.0 mm）正好与盖面齐平。
  - 以后改用插座时，改 `internals.py` 里的 `BOARD_TOP` 和 `shape.py` 外形参数后重跑即可。
- **窗口**：直接按焊盘坐标开。
  - 三条窗口各 32.6 × 8.9 mm，模组四周每边间隙 0.30 / 0.35 mm，底部有 0.5 mm 导向倒角。
  - 模组针脚在本体正中，已按供应商图纸第 3 页像素测量确认。
  - Ø5 开关孔对准 SW1。
- **电池**：两节 18650，按 P28A 包络（Ø18.6 × 65.2 mm）计算，四周间隙约 0.5 mm。
  - 前端预留保护板空间 24 × 19.5 × 7.6 mm（Z × Y × X）。实际保护板尺寸未知。
- **ESP**：YD‑ESP32‑S3 V1.4 包络按厂商公制尺寸图建立。
  - 板子 27.94 × 57.15 mm，天线伸到 63.39 mm。
  - 插在 8.5 mm 母座上，公针塑座 2.5 mm，元件高 3.5 mm。
  - J_test 按已焊计算。
- **尾端面**：
  - USB‑C（J1）：开 13 × 7.2 mm 插头让位口，可直接插线充电。
  - 电源拨杆 SW2：从 5.6 × 2.6 mm 槽伸出，外侧有 2.4 mm 深凹坑。拨杆端高出坑底约 0.2 mm，用指甲拨动，不易误触。
  - 开发板自带的两个 USB‑C 没有开孔，烧录需要开盖。
- **干涉检查**：PCB 157 个元件、15 个模组、ESP、电芯、预留空间共 183 项，全部无干涉（`verification.json`）。最小间隙如下：

  | 部位 | 间隙 | 说明 |
  |---|---|---|
  | PCB 托台 | 0.05 mm | 支撑面 |
  | SW2 拨杆 | 0.30 mm | |
  | 模组与窗口 | 0.30–0.35 mm | |
  | 电芯 | 0.50 mm | |
  | J_test | 0.50 mm | |

## 上下壳连接与装配

1. 电芯、保护板放入前部。PCB（模组已焊、开发板已插）放到两侧托台上。
2. 上盖后端挂钩先插进尾端盖的槽，再以挂钩为轴把前端压下。
   - 上盖在 0–8° 范围内转动不碰任何零件。模组进入窗口只需约 1.2°。
   - 前接缝做成以挂钩为圆心的圆弧，就是为了这个转动。
3. 从前部底面拧入 2 颗 **M2.5 × 30 自攻螺钉**。
   - 下壳通孔 Ø2.9，上盖导孔 Ø2.2。
   - 钉头沉入表面 2 mm。
   - 也可改用热熔铜螺母。
4. 侧面为搭接止口：下壳内唇 1.0 mm，上盖外唇 1.0 mm，径向间隙 0.2 mm。
5. 上盖内有 6 个压板指（X≈8 / 30 / 100，两侧各一），距板面 0.1 mm，防止板子晃动。

## 打印（Bambu Lab H2C，PLA）

- **下壳**：尾端面朝下立着打。
  - 高 238 mm，占地 43 × 46 mm。
  - 握持段和电池段外表面都是竖直壁，不碰支撑。
  - 需要支撑的只有内部前隔板等，约 2600 mm²，可从敞开的一侧取出。
  - 建议加 5–8 mm brim，上部降速。
- **上盖**：分模面朝下、触点面朝上打。
  - 外表面不碰支撑，盖顶内侧需要支撑，可从底部开口取出。
  - 顶面可开熨烫。
  - 也可以倒放打（触点面贴纹理板），但圆角外缘会留支撑痕。
- `Handle_Print_H2C.3mf` 已按上面的方向摆好，约占 272 × 56 mm。导入 Bambu Studio 后选 H2C / PLA 并开启支撑。
- 实心体积折算重量：下壳约 65 g，上盖约 40 g。原手柄两件约 107 g。

各方向的比较见 `printability.json`。
